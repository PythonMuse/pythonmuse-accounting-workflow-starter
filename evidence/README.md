# evidence/

Tie-outs, control-total reconciliations, validation logs, and anything else that proves an output in `outputs/` is correct rather than merely plausible.

This is what a reviewer reads during the Review step (`prompts/08-review-package.md`) — if a number in `outputs/` can't be traced back to something in here and ultimately to `data/raw/`, treat that as a gap, not a formality.
