# skills/

Reusable, tested procedures your AI tool can be pointed at by name (a `SKILL.md` per subfolder), for logic you'll reuse across runs — a reconciliation method, a masking routine, a report format.

Nothing is scaffolded here yet. When a process from this workflow turns out to be reusable, give it its own `skills/<name>/SKILL.md` rather than re-explaining it in a prompt every time.
